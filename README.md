## 快速开始

### 1. 准备手机环境（必做）

照着 **[环境准备](docs/环境准备.md)** 走一遍。

其中**最关键的一步是开启无障碍服务** —— 不做这步，脚本会正常启动、但手机一动不动，
这是新手最常见的坑。

### 2. 拿到脚本

点进 `scripts/` 下对应的脚本目录，下载其中的 `.js` 文件。

也可以直接把整个仓库克隆到手机：

```bash
git clone https://github.com/weisun23/autoxjs-scripts.git
```

### 3. 放到手机上

把 `.js` 文件放进 AutoX.js 的脚本目录，一般是：

```
/sdcard/脚本/
```

用数据线、网盘、QQ/微信传文件都可以，放进去就行。

### 4. 运行

打开 AutoX.js → 脚本列表 → 点一下脚本 → 点运行。

大多数脚本会注册**音量键中断**（按音量上或下随时停止），运行日志会在悬浮控制台里滚动。

## 收录标准

这个仓库不收「看起来能用」的脚本。收录前至少满足：

- **真机跑通完整流程**，不是只跑通第一步
- **有内置自检**：纯函数逻辑（状态判定、边界条件）能在不碰界面的情况下断言通过
- **有中断手段**：不能只能靠强杀进程才能停
- **失败可恢复**：遇到广告落地页、意外弹窗、用户误触，能自己绕回来而不是卡死
- **日志可诊断**：出问题时看日志就知道卡在哪一步

脚本里的选择器、坐标偏移这类依赖具体 App 版本的常量，都会标注**是怎么测出来的**，
方便 App 更新后自己修。

## 常见问题

**Q：脚本启动了，但手机一动不动？**
无障碍服务没开，或开着但没生效。见 [环境准备](docs/环境准备.md)。

**Q：脚本运行中我按了返回 / 切到别的 App，会停吗？**
大概率不会。这类脚本通常会把 App 拉回来继续跑。想停请用音量键，具体看各个脚本的 README。

**Q：能后台运行吗？**
不能。无障碍服务依赖屏幕上的实际控件，熄屏或切走之后控件就取不到了。请保持 App 在前台。
