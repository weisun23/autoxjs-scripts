# 环境准备

跑不通脚本的绝大多数原因都在这一步。**请按顺序做完再运行脚本。**

---

## 1. 安装 AutoX.js

AutoX.js 是 Auto.js 的开源分支，脚本用它的无障碍服务来读取界面、模拟点击。

- 项目地址：<https://github.com/kkevsekk1/AutoX>
- 下载 Release 里的 APK 安装即可
- 本仓库的脚本基于 **AutoX.js v7**（包名 `org.autojs.autoxjs.v7`）测试

> 如果你用的是 Hamibot 或其他 Auto.js 分支，脚本同样能跑（代码里做了配置来源适配），
> 但包名和设置项位置会不一样。

---

## 2. 开启无障碍服务 ⭐ 最关键

**不开启这一步，脚本会正常启动、日志正常滚动，但手机一动不动。**

这是因为脚本所有操作（查找控件、点击、读取页面文字）都要经过无障碍服务。
服务没开时，代码里的 `text(...)`、`click(...)` 全部无效。

### 开启路径

不同系统略有差异，核心都是：

```
设置 → 无障碍（或「更多设置 → 无障碍」）→ 已下载的应用 / 已安装的服务
   → AutoX.js → 打开开关
```

### 验证是否真的生效

把下面这段存成 `test.js` 放到手机脚本目录，运行一次：

```javascript
// 环境自检
auto.waitFor();                 // 无障碍没开时，这一步会一直等
toast("无障碍已就绪");
log("当前应用: " + currentPackage());
log("当前界面: " + currentActivity());
log("能读到的控件数: " + textMatches(/.*/).find().size());
```

判断标准：

| 现象 | 结论 |
| --- | --- |
| 弹出「无障碍已就绪」，且能读到的控件数 > 0 | ✅ 正常 |
| 卡在 `auto.waitFor()` 不动 | ❌ 无障碍没开 |
| 能弹出 toast，但报错 `无障碍服务未启动` | ❌ 无障碍没开 |
| 控件数为 0 | ⚠️ 服务开了但没绑上，关掉重开试试 |

### 小米 / MIUI / HyperOS 特别注意

**MIUI 会在 App 被强杀时自动注销它的无障碍服务。** 也就是说：

- 在最近任务里划掉 AutoX.js
- 在应用管理里点「强行停止」
- 用 `adb shell am force-stop org.autojs.autoxjs.v7`

以上任意一种操作之后，**无障碍开关都会自己关掉**，下次运行脚本前必须重新去设置里打开。

另外 MIUI 的这个开关在「已下载的应用」二级页面里，不在无障碍首页，容易找不到。

---

## 3. 后台运行权限

部分脚本需要主动把目标 App 拉到前台（比如从广告落地页里逃出来）。没有这个权限时，
`launchApp()` 会静默失效——不报错，但 App 不会被拉起来。

**小米 / MIUI / HyperOS：**

```
设置 → 应用设置 → 应用管理 → AutoX.js → 权限管理
   → 后台弹出界面 → 允许
```

**其他系统：** 类似「后台弹出界面」「显示在其他应用上层」「后台启动其他应用」之类的开关。

---

## 4. 电池优化

长脚本（跑几十分钟）会被省电策略杀掉。

```
设置 → 电池 / 省电与电池 → 应用智能省电 → AutoX.js → 无限制
```

顺便在最近任务里给 AutoX.js 加锁（下拉图标上有锁），防止被一键清理。

---

## 5. 传脚本到手机

脚本目录一般是 `/sdcard/脚本/`（部分版本是 `/sdcard/AutoX/`，以 App 内显示的为准）。

传输方式随便挑：

- **数据线**：开 USB 调试，用 `adb push 脚本.js /sdcard/脚本/`
- **网盘 / QQ / 微信**：传到手机后，用文件管理器移动到脚本目录
- **git**：手机上装 Termux 或直接用支持 git 的文件管理器克隆本仓库

---

## 6. 常见问题

**Q：脚本日志在滚，但手机没反应**
无障碍服务没开或已失效。见第 2 节，重新打开。

**Q：跑一会儿就停了，日志没有报错**
多半是被省电策略杀了。见第 4 节。

**Q：点击没反应，但控件能找到**
有些界面（WebView 渲染的弹窗）不响应 `press()`，只响应 `click()`。
如果某个脚本在你机型上卡住，把现象和日志提到 Issue。

**Q：熄屏 / 切到别的 App 还能跑吗**
不能。无障碍只能读到屏幕上真实存在的控件，脚本必须让目标 App 保持在前台。

**Q：能不能同时跑多个脚本**
不建议。多个脚本实例会互相抢操作，日志里会出现成对重复的行，行为不可预测。
换脚本前先按音量键停掉上一个。
